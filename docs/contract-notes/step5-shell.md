## Contract problems

1. **`CommonSurfaceCheck.swift`, the coordinator's exception.** D25's `TriageIntent.nextPending` broke the exhaustive switch over `TriageIntent?` at line 380; `.nextPending?` was added to that one `case` line, and nothing else in the file changed. Plan §11.3 prints `TriageIntent`: the docs pass adds the case there.
2. **Ollama is on by default, so D5's switch cannot make it the default on a first launch.** `DefaultSettings.make()` (RefereeCore, frozen) ships Ollama switched on with no review default, and `applyFirstRunDefaultsIfNeeded()` (AppCore) acts only when Ollama is running at launch. On a first launch without a running Ollama, Settings therefore shows Ollama already on, and the D5 rule "switching a provider on makes it the review default" never runs for it; D5's manual check ("switch it on in Settings, open a PDF: the indicator reads Local") needs the switch turned off and on, or the Review default chosen in the bar. *Inside the Shell:* the window says "Choose AI provider" and its menu offers Ollama for the paper (D5.4); the welcome window still says "Set Up AI Provider…", which leads to Settings. *Suggested:* ship Ollama off in `DefaultSettings` (then the first switch makes it the default, and D21's start box shows on a first run), or run `applyFirstRunDefaultsIfNeeded()` again when the app becomes active while there is no review default.
3. **No other.** O1 and O2 were enough; a nil `chatProvider` or `reportProvider` is not named (decided above, as the step 5a notes asked).
